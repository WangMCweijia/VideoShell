01暗→亮的五条转译规则

不是"换个配色"，是同一套物理在白天的样子。每条都可对照检查。

暗场（Dark Stage）白昼（Daylight）转译
黑场画布 #0A0C10暖纸画布 #F6F5F2：不是纯白也不是冷灰，暖调承接"放映室"气质；上缘微亮 vignette 保留（光源在天的方向）。
e1/e2/e3 色阶靠提亮色阶靠实白 + 浅墨描边 + 投影：e1 = 纯白面板，e2 = 白卡 + #E2DFD8 发丝线 + 极淡投影。亮色下"明度分档"空间小，层次改由描边与投影承担。
白 8% hairline墨 12% hairline（#E2DFD8）：极性反转但职责不变——面板的"折边"。
海报主色光溢出（12–18% alpha）烫金投影（30% 不透明度、更小半径）：暗场里光是"洒出来的"，白昼里光变成"纸面下的暖影"——海报底下那团暖影依然来自海报主色，来源规则不破。
琥珀上深墨文字原样保留；琥珀做文字时加深为 amber_text #B87A10（#E8940F 在白底只有 2.4:1，只许当图形色）。

播放页 · 永远暗场 —— 亮色系统下也保持黑场

3.1 设计决策：播放页为什么不做亮色变体

放映厅里没有白天。播放器是环境光最暗的场景，视频画面本身是暗底内容： 亮色控制栏压在视频上会产生"白条压黑画"的撕裂感，且系统主题切换会造成观看中突兀闪变。 规则：播放页（含画中画、横屏）固定使用暗场材质，不随系统主题走； 这也是 YouTube / Netflix / 哔哩哔哩播放器的通行做法。实现上 = PlayerActivity 强制 AppCompatDelegate.setDefaultNightMode(YES) 局部生效，改动一处。

04亮色组件关键差异

组件白昼表达
主按钮「识别并添加」琥珀渐变原样 + 深墨文字 + 琥珀色投影（暗场里投影是黑的，白昼里换成琥珀 35% 让按钮像一盏灯）。
选中 Tab 胶囊 / 分类芯片同一条琥珀渐变 + 琥珀投影；未选中 = 白底 + 发丝线（暗场是 e2 底）。
状态徽章14% 透明同色底不变，但状态色压暗回白天档（ok #1E9E5A / bad #D64545 / 灰 #7C8797）。
进度条琥珀渐变原样；末端光点的 glow 在白昼下收小到 4dp——"光点"在纸上不能糊成一团。
骨架屏e2 暖灰块 + 微光扫过不变；高光带在白昼用纯白 40%。
按压态e3 提亮（#F1EFE9）+ scale 0.98；暗场是提亮，白昼是压暖，触感等价。
光溢出 spill30% 不透明度、半径 ×0.6、模糊 13dp——"烫金投影"参数，与暗场（50%/16dp）分开调。
