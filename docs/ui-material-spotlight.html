VIDEOSHELL · UI 2.0 MATERIAL REDUX

材质重设计：
暗场 Spotlight —— 内容即光源

磨砂玻璃的逻辑是"介质感"——让界面像一层可透的材质。现在换一套更贴合视频产品的物理： 把界面当成一间暗场放映厅。画布近乎全黑，海报是唯一发光体，光从内容里溢出来； 面板是实底分层结构，靠色阶与发丝线建立层次；唯一的高饱和色是一束"聚光琥珀"， 只落在进度、选中态和主按钮上——用户视线永远被光引向正在发生的事。

替代「磨砂玻璃浮岛」材质 暗色为第一主题 零 blur · 低端机友好 2026-09-23 · v2 草案

01为什么换材质

玻璃不是不好，是在这个产品里有三条更硬的理由换掉它。

理由说明
内容属性更合拍视频 App 的主角是海报与画面。玻璃迫使"界面感"浮在内容之上；暗场逻辑相反——界面退成黑场，内容自己发光。用户注意力的去向，正好是产品想引导的方向。
性能账半透明浮岛依赖 RenderEffect / 硬件 blur 层，minSdk 21 的低端机上是最贵的效果之一。新材质零 blur、零背透，只剩纯色 + hairline + 阴影，绘制成本降到最低。
可读性从"守"变"稳"玻璃方案里文字压在不可控的透出内容上，永远要靠透明度纪律去"守"可读性（v1.0.49 的反复调参都是这件事）。实底材质让对比度变成静态可验证的常量，一次达标、永远达标。

保留清单（不动的东西）

保留 三 Tab 信息架构与导航位置 · 保留 海报 3 列 / 1:1.4 / grid_gap 6dp · 保留 字号阶梯（11–22sp）与间距体系 · 保留 圆角尺度（6–20dp）· 保留 站源页 1 主 + 3 次的动作收敛 · 保留 状态三态徽章（正常/失联/未体检）· 保留 brand 蓝降级为信息/链接色（不删除，识别不丢）

02三个候选方向

先开阔再收敛 —— 每个方向都做了一句气质判断。

A · 暗场 Spotlight
黑场画布 + 实底分层 + 琥珀聚光。气质：放映厅、仪器、克制的光。
选定 内容即光源，与产品心智零摩擦；暗色是默认主题，成本最低。
B · 纸感编辑风
暖白纸底 + 细规则线 + 大字号衬线标题。气质：电影杂志、排印。
气质独特，但列表型工具产品里规则线密度高、易显旧；亮色优先与产品默认暗色相悖。
C · 曜石冷光
深灰蓝面板 + 冷蓝发光描边。气质：科技、电竞。
冷光描边容易滑向"电竞风"，与"全年龄看片工具"的气质错位；蓝色主强调也是 AI 界最俗的组合。

03材质 Token

三套新体系：色阶面板 · 聚光琥珀 · 光溢出。玻璃四层材质（fill/glow/stroke/edge + ambient）整体退役。

3.1 层级面板（暗 · 默认主题）—— 深度靠色阶，不靠透明

e0 stage 画布#0A0C10 · 页面底
e1 panel 面板#12161D · 导航/顶栏/面板
e2 card 卡片#191E27 · 行卡/输入框
e3 lift 提亮#222834 · 按压/悬停

每级之间只差一档明度，配 8–10% 白 hairline 描边与向下投影；禁止跨级跳色（e0 直接叠 e2 会被读成"洞"）。

3.2 聚光琥珀（唯一高饱和强调色）

amber 渐变#FFC46B→#E8862C · 进度/选中
amber 实底#F0A63C · 主按钮/焦点
amber_ink#201405 · 琥珀上的文字
amber_text#B87A10 · 亮底文字用
info（原brand）#5D95F7 · 链接/信息，不承载强调
spill_* 光溢出取海报主色的 12–18% alpha

3.3 光溢出（Spill）—— 新材质的"灵魂动线"

规则只有一条：光只从内容里来。每张海报卡在底部投一团海报主色的柔光（Coil 取主色或按分类预置渐变，12–18% alpha，模糊 12–16dp）； 播放中的卡片光晕随播放呼吸（透明度 ±4%）。界面里不存在无来源的光——没有背光斑、没有发光描边、没有渐变装饰。 这是暗场方案与"发光电竞风"的分界线。

实现代价：每卡一个低档模糊 Bitmap 或 9-patch 光斑，列表复用回收，无 blur API 依赖，minSdk 21 可用。

05组件规范（更新项）

结构沿用上一版方案（三层级按钮 / 状态徽章 / 空态骨架），只更新材质表达。

按钮 · 三层级（暗底实拍）
识别并添加 取消 网页浏览 ›

主按钮 = 琥珀渐变 + 深墨文字（白字在琥珀上只有 2.1:1，禁用）； 次级 = e1 实底 + hairline；三级 = 琥珀文字（亮底下换 amber_text）。 按压统一 e3 提亮 + scale 0.98。

分类芯片
推荐电影剧集综艺
状态徽章（暗底实拍 · 语义沿用）
正常 失联 未体检

实底色块 → 14% 透明同色底：状态色仍然三态唯一，但从"贴纸"变成"灯"。

骨架屏

海报位 = e2 灰块 + 微光扫过（琥珀 4% 高光带，1.2s/次）——骨架屏的"微光"是暗场里唯一允许的装饰性动效。

进度条

全 App 唯一进度表达：琥珀渐变 2.5dp + 末端光点（8dp 圆点 + 8dp glow）。卡片续播 / 播放页 / 下载进度共用，禁止再出现蓝色 ProgressBar。

06动效（更新项）

节奏不变（150–300ms / ease-out 家族 / 尊重 duration_scale=0），材质表达换光。

stage→e1 + hairline 淡入 · 220ms
光溢出呼吸
播放中 spill ±4% · 2.4s 循环
场景规则
页面进入内容先亮：海报卡从 4% 透明 + 12dp 下移淡入，首屏前 6 张错峰 30ms；面板不做入场动效——暗场里只有内容在动。
进度推进光点位置变化不做补间拖影；琥珀填充平滑跟随。
状态变化徽章底色 200ms 颜色过渡（灰→绿），同上一版。
禁用清单无发光描边动画、无霓虹脉冲、无视差光斑 —— 光只属于内容与进度。
